01 · 測試資料

Generate all setters cache name values

呼叫所有 setter 並填入範例值

快速建立測試資料。數字依屬性名稱固定：兩次產生的 age 都是同一個數字，方便建立兩個內容相同的物件來比對。

  1. 游標放在區域變數的名稱上（必須是宣告敘述）。
  2. 按 Alt + Enter，選擇此項。
  3. 在宣告的下一行產生該類別（含父類別）所有 setter 的呼叫。
範例值規則：String 用屬性名稱大寫（"NAME"）、數字加上型別字尾（1L、1d、(short) 1）、boolean 為 true、日期為 LocalDate.now() 等，其他型別為 null。
關聯程式
  • GenerateAllSetterFieldNameAction
  • BaseGenerateAllSetterFieldNameAction 共用流程
  • core · codegen/CodeGenerators.setterCalls
  • core · codegen/SampleValues 範例值
  • core · codegen/NumberSequences.perProperty
  • PsiAccessors、CodeInserter
BEFORE
User user = new User();
→ AFTER
User user = new User();user.setName("NAME");user.setAge(1);user.setBirthday(LocalDate.now());user.setActive(true);user.setAddress(null);user.setId(2L); // 繼承自父類別
02 · 測試資料

Generate all setters no cache values

同上，數字每次都不同

操作與 01 相同。差別在數字：每個數字欄位都拿新的流水號，適合需要不重複資料的情境，例如主鍵。

  1. 游標放在區域變數名稱上。
  2. 按 Alt + Enter，選擇此項。
IntelliJ 的預覽畫面不會消耗號碼，只有真正執行才會前進。
關聯程式
  • GenerateAllSetterNoCacheNameAction
  • BaseGenerateAllSetterFieldNameAction

03 · 物件轉換

Generated set/get based on parameter 1 as parameter 2

把參數 2 的屬性複製到參數 1

撰寫 mapper。只產生參數 1 有 setter、參數 2 也有 getter 的屬性，不會產出編譯不過的程式。

  1. 方法簽章為兩個物件參數：void map(Target t, Source s)。
  2. 游標放在方法內的空白行。
  3. 按 Alt + Enter，選擇此項。
關聯程式

  • CaretStatementsIntention 游標位置與插入

→ AFTER
void map(UserDto target, User source) {    target.setName(source.getName());    target.setActive(source.isActive());}

07 · 安全

Generate fix sql injection related declare parameters

把串接進 SQL 的值改成綁定參數

消除字串串接造成的 SQL injection。值換成 :name（具名）或 ?（依序），並在該行之前宣告參數集合、放入每個值。

  1. 游標放在 SQL 字串串接的任一處，例如變數或字串上。
  2. 按 Alt + Enter，選擇此項。
  3. 把執行 SQL 的程式改成 PreparedStatement 或 NamedParameterJdbcTemplate，並傳入參數集合。外掛不會改這一步。
自動處理：
  • 引號內的整段值成為一個參數，LIKE '%…%' 的 % 會移到參數值中
  • dto.getId() 等方法呼叫也會綁定
  • static final 常數與 sql = sql + … 的累加變數保留不動
不會修改、改為顯示提示的情況
  • ORDER BY、表格或欄位名稱：請改用白名單檢查
  • IN (" + ids + ") 整串：請展開成多個 ?
  • 值黏在 SQL 字詞上，或引號不成對
關聯程式
  • GenerateMapFromStringWithDeclareAction
  • SqlInjectionFixIntention 共用流程
  • SqlConcatenation 拆解串接運算式
  • core · sql/SqlParameterizer 引號追蹤與綁定
  • core · sql/ParameterCodeGenerator
  • configurable/MyPluginSettings 綁定樣式
BEFORE
String sql = "SELECT * FROM T_USER"    + " WHERE NAME = '" + name + "'"    + " AND ID = " + id;
→ AFTER（Use Named）
Map<String, Object> parameters = new HashMap<>();parameters.put("name", name);parameters.put("id", id);String sql = "SELECT * FROM T_USER" + " WHERE NAME = :name" + " AND ID = :id";
08 · 安全

Generate fix sql injection related without declare parameters

同 07，但不宣告參數集合

方法前面已經宣告過參數集合時使用，只產生放入參數的敘述。右側範例為設定成 Use Ordered 時的輸出。

  1. 確認參數集合變數已存在，名稱與設定頁相同（預設 parameters）。
  2. 游標放在 SQL 串接上，按 Alt + Enter。
關聯程式
  • GenerateMapFromStringWithoutDeclareAction
  • 其餘同 07
BEFORE
sql += " AND NAME LIKE '%" + name + "%'";
→ AFTER（Use Ordered）
parameters.add("%" + name + "%");sql += " AND NAME LIKE ?";
09 · 防呆

Add 'value != null' check

在 if 條件前加上 null 檢查

避免 NullPointerException。原條件含 || 時會自動加上括號，維持運算順序。

  1. 游標放在 if 條件中 value.method() 的 value 上。
  2. 按 Alt + Enter，選擇此項。
變數是基本型別、或條件裡已經有 value != null 時，不會出現此選項。
關聯程式
  • AddNullCheckAction
BEFORE
if (value.isEmpty()) {…} if (b || value.isEmpty()) {…}
→ AFTER
if (value != null && value.isEmpty()) {…} if (value != null && (b || value.isEmpty())) {…}
10 · 閱讀輔助

String / StringBuilder Quick Documentation

看出動態組出的 SQL 全貌

在 String、StringBuilder、StringBuffer 變數上開啟快速文件，列出所有累加的內容，並保留 if／else／switch／迴圈結構。

  1. 游標放在變數上。
  2. 按 Ctrl + Q（macOS F1），或滑鼠停留在變數上。
常數與區域字串變數會代入實際值；無法得知的值顯示為 ${運算式}。new StringBuilder(100) 的容量不會當成內容。

安裝

需要 IntelliJ IDEA 2024.1（build 241）以上，Community 或 Ultimate 皆可；功能作用於 Java 檔案。

從 Marketplace 安裝

  1. Settings → Plugins → Marketplace
  2. 搜尋 Values（ID：com.h8000572003.intellijplugin）
  3. 按 Install，依提示重新啟動 IDE

想搶先試用開發中的版本：Settings → Plugins → ⚙ → Manage Plugin Repositories 加入 https://plugins.jetbrains.com/plugins/eap/list，即可收到 EAP 版更新。

從 zip 檔安裝

  1. 取得 values-<版本>.zip：GitHub Releases、Actions 的 plugin-zip artifact，或本機執行 ./gradlew buildPlugin
  2. Settings → Plugins → ⚙ → Install Plugin from Disk…
  3. 選擇 zip（從 Actions 下載的 artifact 需先解壓出裡面的外掛 zip）

設定：Values Settings

位置：Settings → Tools → Values Settings。這兩個選項只影響 07、08 的 SQL injection 修正。

Settings › Tools › Values Settings
Choose use sql generate role: Use Named Use Ordered
Enter parameter name: parameters

選項說明

  • Use Named（預設）：SQL 寫 :name，參數放進 Map<String, Object>，搭配 NamedParameterJdbcTemplate 等。
  • Use Ordered：SQL 寫 ?，參數依序放進 List<Object>，搭配 PreparedStatement。
  • parameter name：產生的參數集合變數名稱；留白時使用 parameters。
